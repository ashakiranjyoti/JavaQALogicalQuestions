## Coding Style Used

The programs are intentionally written in a simple Java style:

- Most logic is directly inside `main()`.
- Basic `if-else`, `for`, `while`, arrays and strings are preferred.
- Java collections such as `HashMap`, `HashSet` and `ArrayList` are used only where they make the logic simpler.
- Each file contains its own simple explanation, important keywords and flow.

## Practice Method

Read the question -> understand the logic -> close the file -> write it yourself in VS Code -> run it -> compare the result.
